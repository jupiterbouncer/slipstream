How Slipstream works

Slipstream is engineered for direct peer-to-peer file transfer between devices on the same local network without cloud storage:

  • Session Creation: The sender generates a temporary 6-digit code and QR code.
  • Signaling Only: The lightweight PHP/MySQL backend coordinates WebRTC connection metadata (SDP offer/answer and ICE candidates).
  • Direct Data Channel: Once connected, browsers communicate directly over an RTCDataChannel with DTLS encryption.
  • Zero Server Storage: Your file bytes never touch the server or any third-party cloud.

Privacy & Security

We believe in transparent, verifiable privacy:

  • No Accounts: No sign-ups, passwords, or personal profiles.
  • Ephemeral Data: Pairing records expire automatically after 10 minutes and are completely purged from the server.
  • Brute-Force Protection: Pairing lookups are rate-limited using one-way cryptographic hashes.
  • In-Transit DTLS Encryption: WebRTC data channels enforce end-to-end DTLS encryption between the two peer browsers.

Connection Diagnostics & Help

Troubleshooting WebRTC Connections:

  • Ensure both devices are connected to the same Wi-Fi or local network.
  • Check that your firewall or router allows local UDP traffic.
  • If accessing from a mobile device over a LAN IP address, modern browsers may require HTTPS to enable secure context features.
  • Pairing codes expire after 10 minutes; if expired, create a fresh session on the sender device.
